# SIGNAL / PLUGINS — бесплатный Telegram-дайджест

Проект ежедневно собирает новости из RSS-лент и отправляет до 8 новых публикаций в Telegram. Работает на GitHub Actions: VPS не нужен.

## Важно: как правильно загрузить архив

Загрузите **содержимое** архива в корень репозитория GitHub. Не создавайте дополнительную вложенную папку `vst_digest_starter`.

После загрузки структура репозитория должна выглядеть так:

```text
.github/
  workflows/
    daily-vst-digest.yml
.gitignore
main.py
requirements.txt
README_RU.md
```

Папка `.github` скрытая (начинается с точки), но GitHub обязан видеть её в корне репозитория. Workflow-файл должен находиться в основной ветке репозитория (обычно `main`).

## 1. Создайте Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` и следуйте инструкциям.
3. Скопируйте токен бота. Не публикуйте его и никому не отправляйте.
4. Создайте Telegram-канал.
5. Добавьте бота в канал администратором с правом публикации сообщений.
6. Для публичного канала `TELEGRAM_CHAT_ID` обычно имеет вид `@имя_канала`.
   Для приватного канала проще всего получить числовой chat ID через проверку обновлений бота после добавления бота в канал. Не передавайте токен сторонним сайтам.

## 2. Создайте GitHub-репозиторий

1. Войдите на [github.com](https://github.com/).
2. Нажмите **New repository**.
3. Назовите его, например, `vst-digest`.
4. Для простоты можно выбрать **Public** (код не содержит секретов). Private тоже подходит, но у GitHub Free есть лимиты минут Actions.
5. Создайте репозиторий.

Загрузите файлы из архива в корень репозитория. Самый надёжный способ — распаковать архив на компьютере и загрузить папку `.github` вместе с остальными файлами через Git или GitHub Desktop. При загрузке через веб-интерфейс убедитесь, что `.github/workflows/daily-vst-digest.yml` действительно попал в репозиторий.

## 3. Добавьте секреты

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**.

Создайте два секрета:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather.
- `TELEGRAM_CHAT_ID` — `@username` публичного канала или числовой ID приватного канала.

Значения не нужно записывать в файлы проекта.

## 4. Включите GitHub Actions

Откройте **Actions**. Если GitHub предлагает включить Actions, нажмите **I understand my workflows, go ahead and enable them** (или аналогичную кнопку).

Если workflow не появляется:
- проверьте, что файл называется ровно `daily-vst-digest.yml`;
- проверьте путь `.github/workflows/daily-vst-digest.yml`;
- проверьте, что файл находится в основной ветке (`main` или выбранной default branch);
- откройте **Settings → Actions → General** и разрешите запуск Actions;
- убедитесь, что в YAML есть `name: Daily VST digest` и `on:` на верхнем уровне.

## 5. Первый запуск вручную

1. Откройте **Actions → Daily VST digest**.
2. Нажмите **Run workflow → Run workflow**.
3. Откройте запущенный процесс и проверьте журнал.
4. Если всё настроено, бот отправит пост в канал.

Расписание: ежедневно в 07:00 UTC, то есть в 10:00 по Москве. GitHub Actions не гарантирует запуск ровно в минуту расписания; возможна задержка.

## Источники и поведение

Начальная версия читает RSS:
- KVR Audio: `https://www.kvraudio.com/news-feed.php`
- Bedroom Producers Blog: `https://bedroomproducersblog.com/feed/`
- rekkerd.org: `https://rekkerd.org/feed/`

Скрипт выбирает записи с аудио- и plugin-ключевыми словами, публикует максимум 8 новых материалов и сохраняет их ID в `state.json`, чтобы не отправлять их повторно. История сохраняется коммитом GitHub Actions.

Если новых материалов нет, публикация пропускается. Если RSS-источник временно недоступен, остальные источники продолжают обрабатываться.

## Бесплатность и ограничения

- GitHub Actions имеет бесплатные лимиты, зависящие от типа репозитория и аккаунта.
- Telegram Bot API для обычной публикации сообщений бесплатен.
- В этой версии нет платного ИИ и нет VPS.
- Скрипт не гарантирует, что каждая запись — именно новый VST-релиз: фильтр по ключевым словам — стартовая версия. Позже можно добавить ИИ-редактуру и более точные категории.

## Частые проблемы

**Workflow не отображается во вкладке Actions**
Почти всегда причина — неправильный путь/имя файла, файл не в default branch или Actions отключены. Нужен именно путь `.github/workflows/daily-vst-digest.yml`.

**Telegram отвечает `chat not found`**
Проверьте `TELEGRAM_CHAT_ID`, а также что бот добавлен в канал администратором. Для публичного канала используйте `@username`.

**Telegram отвечает `Forbidden: bot is not a member of the channel`**
Добавьте бота в канал и выдайте ему право публикации.

**Ошибка `Bad Request: can't parse entities`**
Скрипт использует HTML-разметку Telegram и экранирует текст заголовков и описаний. Если ошибка повторится, посмотрите конкретную запись в Actions log.

**Ничего не опубликовано**
Возможно, сегодня не нашлось новых записей по ключевым словам. Проверьте лог запуска: он показывает число записей, полученных из каждого RSS.
